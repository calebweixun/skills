# domain-modeling

來源：[mattpocock/skills](https://github.com/mattpocock/skills)
的 `skills/engineering/domain-modeling/`（MIT License）。

主動建立與收斂專案的領域模型：在設計過程中挑戰術語、發明邊界情境、當下就把
glossary（`CONTEXT.md`）與架構決策（`docs/adr/`，格式見 `ADR-FORMAT.md`）寫下來，
而不是事後補。跟「只是讀 `CONTEXT.md` 查詞彙」不同——這個 skill 是*改動*模型時用的。

本地版本用詞與上游略有差異（語氣微調，非結構性差異），非逐字同步，之後上游更新時
可另外比對是否要跟進。
