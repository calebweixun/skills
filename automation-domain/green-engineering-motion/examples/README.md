# 範例影像

僅含 MG 本身的分鏡（白底／深底，無老師、無簡報截圖），用來對照目標的比例、密度與版面模式。

- `episode-storyboard.jpg`：整集範例（`templates/episode`）各段分鏡；`center` 片頭與片尾為深底，其餘為白底，右側（x ≥ 1280）留給老師。
- `single-page-storyboard.jpg`：單頁範例（`templates/single-page`）逐步建構的 12 個時間點；粉紅區是老師保留區。

ep0 開場（老師置中）的參考畫面含老師影像，不隨技能分享；對應程式見 `templates/episode/examples/opening-page.js`。
