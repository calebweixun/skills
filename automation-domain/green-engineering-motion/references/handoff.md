# 單頁任務提示與交接欄位

每個新對話貼一份任務。填入頁碼和最想強調的內容即可；若重點還沒決定，可請 agent 從原頁選擇並說明。

`$green-engineering-motion` 是已安裝的個人技能名稱。為了讓沒有自動載入技能的對話也能工作，提示同時提供實際 SKILL.md 路徑。

## 每頁完成後的交接

請負責該頁的 agent 在自己的資料夾留下簡短說明，包含：

- 原始頁碼／標題、來源版本、教學重點。
- 動態物件、動作順序與最後位置，哪些可調整。
- 畫布、精確 FPS、總影格數、實際片長、背景／alpha。
- 預覽埠、啟動方式、輸出與素材路徑。
- 已做的實際檢查，以及仍需使用者決定的內容。

這些資料應足以讓另一個對話修改單一頁面，而不用回讀整段片頭製作歷史。
