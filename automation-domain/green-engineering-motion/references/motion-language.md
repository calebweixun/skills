# 動作偏好與經驗

## 這次修正得到的關鍵判斷

使用者最後對片頭的要求是：地球迅速轉到中央，稍慢停留；其他物件同時進場；整組略帶卡通電影感轉向右下角；邊框物件進場時帶出白色背景。

先前把整段時間套上「前慢後快」曲線，造成地球一開始太慢。後來改成獨立段落，分別控制抵達、停留、同步環繞、轉向、落位及框景轉白。這是最值得沿用的做法：**依動作意圖分段，分別調整速度曲線。**

## 動作詞如何落到實作

| 使用者的意思 | 適合的做法 | 畫面驗收 |
| --- | --- | --- |
| 迅速到中央後稍慢 | 快速平移＋旋轉，用 ease-out 收住；抵達後有短暫停留或慢速細動 | 主物件早期已接近觀看位置，觀眾有時間辨識 |
| 其他物件同時進場 | 同一開始時間、共用主要進度和淡入區間；依 endpoint 分散路徑 | 同一時間能看出一組物件加入，留意前後遮擋造成的視覺延遲 |
| 轉向右下角快一點 | 集合為父群組，轉場另設較短的移動段，保留前後可讀停頓 | 中段有明顯加速，沒有把整個片段改成倍速 |
| 略帶卡通電影感 | 小幅反向蓄勢、向移動方向傾斜、輕微 squash/stretch，再回彈 | 動作有重量和方向，圖示最後恢復正確比例 |
| 定位時有一點彈 | 沿移動方向小幅越過 endpoint，一次主要回彈後衰減 | 能感覺到彈性，最後完全穩定 |
| 邊框先快後慢 | 以 ease-out 驅動路徑弧長或 draw range，飾帶也使用相應減速 | 最初一小段時間完成較多距離，後段慢慢收住 |
| 邊框帶入白底 | 背景 reveal 和框景共用開始時間與方向關係 | 框景到來前保留原背景，框景出現時才開始轉白 |

平移、旋轉、縮放與透明度可共用主進度，也可以保留合理的分工。例如快速移動並不需要文字標籤同樣快速旋轉。

## 片頭的數值是案例

02.2 的已驗證時間安排：

- 0.05–1 秒：地球快速轉入中央；1–1.35 秒稍作停留。
- 1.35–3.9 秒：周邊元件同步環繞進場。
- 3.9–4.45 秒：呈現完整關係。
- 4.45–4.8 秒：小幅反向蓄勢。
- 4.8–7 秒：整組轉往右下角，傾斜、輕微形變與回彈後定位。
- 7.15 秒起：邊框、藍色飾帶和白底轉場一起發生。
- 9.9–12.012 秒：完全定格。

地球在 1.05 秒時的畫面座標已實測為 (960, 540)。這個結果可參考「快速到位」的節奏，但單頁圖示的大小、位置、時長應配合本頁。

先前小幅落位回彈的量級約為 10–20 px、縮放約 2%，適合作為 1080p 構圖的起始調整範圍。這些是案例參數；小型圖示、長文字或不同構圖需重新目視評估。

## 套用到單頁重點動畫

先寫一句觀看後要理解的內容，例如「顯示三個部件如何連動」或「標出訊號從哪裡流到哪裡」。從原頁決定要動的物件、要保留的標籤、觀看順序與最後畫面。

建議安排為「快速聚焦 → 主要關係或過程 → 穩定閱讀」。同層級項目可同步；如果順序本身是知識的一部分，依教學因果逐步呈現。

對於循環過程，使用一個完整週期並檢查接點。對於需要講師解說的圖示，安排足夠的最終穩定畫面。文字較多時，縮短裝飾旋轉、增加閱讀停頓。

片頭的星點、地球大近景、移到右下角、對角轉白，僅在本頁需要時使用。課程內容圖示可直接沿用白底版型或透明背景，讓主要工程關係更容易理解。

## 常見需要修正的情況

- 只有加快播放速度：觀眾仍可能覺得第一段拖慢，應先改分段時長與速度分配。
- 程式設定同時開始，但有些圖示被遮住或在畫面外：應檢查實際看見的時刻和構圖。
- 物件在畫面中央仍持續大幅旋轉：會妨礙辨識，抵達後應降低速度或停留。
- 群組旋轉造成整張構圖漂移：重新計算 pivot 與位移，確認縮放和轉向圍繞預期中心。
- 回彈一直微動：加入有限時間的衰減，終點明確重設，避免尾段細微晃動。
- 背景已轉白才出現邊框：把 reveal 與框景綁在同一轉場事件。

目視檢查進場、中段、抵達前後與定格；只比對數值或最後一張圖無法判斷整段節奏。
