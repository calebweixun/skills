# 人像調色與清晰度

適用情境：老師在綠幕前錄影，經 Ultra Key 去背後疊在 MG 背景上。背景可能是暗底、白底或中間調。

## 量測框怎麼選

先匯出畫面並用 Read 看過，再決定座標（1920×1080）。人物的位置和大小每一段都可能不一樣，所以**每張圖都要重新框**。

| 區域 | 選法 | 避開 |
|---|---|---|
| 臉頰 | 眼睛下方到嘴角之間，約 100×70 | 眼鏡反光、鼻樑高光、鬍渣陰影 |
| 額頭 | 眉毛上方的橫條 | 頭髮 |
| 衣服 | 胸口或腹部平坦處，約 120×140 | 麥克風、鈕扣列、手 |
| 背景 | 人物旁邊沒有文字和圖示的空白處 | 字卡、陰影 |
| 銳利度 | 眼睛到眼鏡一帶，約 180×100 | — |

```powershell
pwsh -File scripts/measure.ps1 -Image f_90.png -Regions "face=1470,390,1570,450;forehead=1450,300,1590,325;shirt=1290,700,1410,850;bg=1250,150,1400,250" -Sharpness "eyes=1430,320,1610,420"
```

## 目標區間（sRGB 0–255，供起點參考）

| 指標 | 目標 | 說明 |
|---|---|---|
| 臉頰 Y | 130–160 | 低於 120 看起來暗沉。白底段可以抓在區間的上緣 |
| 皮膚 R/G | 1.15–1.25 | 低於 1.12 偏黃綠（日光燈），高於 1.3 偏紅 |
| 白或淺色衣服 R/G | 0.97–1.03 | 低於 0.95 偏青、偏冷，看起來會「死白」 |
| 衣服過曝比例 | < 2% | 指 R、G 都 ≥ 250 的像素比例 |
| 衣服 Y − 臉頰 Y | 約 40–70 | 差距太大時，觀眾會覺得人「偏白但不夠亮」 |
| 銳利度（Laplacian） | 只看前後相對變化 | 隨素材差異很大，不設絕對值 |

最後仍以使用者看過的感受為準。案例中臉頰 Y 只做到 127（暗底）與 136（白底），使用者已經接受；數值不必硬拉到區間中央。

## 症狀對照表（Lumetri 基本校正，除非另外註明）

| 看到的現象（數據） | 先動哪個參數 | 每次調整幅度 |
|---|---|---|
| 臉暗（Y 偏低） | 曝光 + | 0.2–0.3 |
| 衣服太亮、過曝 | 白色 −、亮部 − | 10 |
| 臉和衣服亮度差太大 | 白色 −、曝光 +、陰影 + | — |
| 皮膚偏黃綠（R/G 偏低，日光燈） | 色調 +（往洋紅） | 2–3 |
| 整體偏冷、衣服偏青 | 色溫 + | 3–5 |
| 膚色太粉 | 色調 − | 2 |
| 臉灰、沒精神 | 鮮明度 + | 5 |
| 頻閃明顯 | 對比 −（只能讓它比較不明顯） | 5 |
| 白底上人物顯得灰暗 | 白底組的曝光比暗底組高 0.3 左右，陰影也加 | — |

注意：降白色、降亮部、降對比都會抵銷曝光的效果。動完這幾項，一定要**重新量測**臉部亮度。案例中曝光 +0.25 搭配這些降幅，臉部 Y 幾乎沒變，只好再加一輪曝光。

## 背景分組

在人物以外量一塊背景的平均亮度，依此分組：暗底（< 80）、中間調（80–200）、白底（> 200）。各組的色彩參數（色溫、色調、鮮明度、白色、亮部、對比）共用一套；曝光、陰影、黑色則每組分開設定。

## 清晰度

依序檢查下列項目，每一項都要做前後量測：

| 原因 | 參數 | 案例的調整 | 注意 |
|---|---|---|---|
| 完全沒加銳利化 | Lumetri「創意 → 銳利化」 | 0 → 35 | 超過 40 容易放大壓縮雜訊和頻閃 |
| 去背邊緣糊 | Ultra Key「柔化」（Soften） | 30 → 12 | 低於 10 頭髮邊緣可能出現鋸齒，要放大檢查 |
| 磨皮過度 | HSL 次要校正「校正 → 銳利化」為負值 | 原本 −19，未修改 | 同名參數，需 `execute_extendscript`（要使用者同意）或請使用者手動改 |
| 縮放小於 100% | Motion 的 Scale | 95，未修改 | 會重新取樣，影響小 |
| 監視器解析度太低 | 節目監視器的播放解析度 | — | 設成 1/2 或更低時，畫面看起來就會糊；請使用者改成「完整」再判斷 |

案例數據：套用銳利化 35 和柔化 12 之後，眼睛區域的 Laplacian 能量從 95 升到 306，衣服區域從 59 升到 212。使用者看 1:1 原尺寸對照圖後同意全面套用。

對照圖要用 **1:1 原尺寸**裁切，例如臉部 440×380。縮小後的圖看不出清晰度差異。

```powershell
pwsh -File scripts/compare.ps1 -Images before.png,after.png -Crop 1330,250,440,380 -Out cmp_sharp.png
```

## 案例參考：綠色工程課程（2026-11，ep0／ep1）

錄影條件：vMix 輸出的 SpeedHQ 1080p，綠幕，現場是日光燈。原始 Lumetri：色溫 −5、色調 −3.3、曝光 0.2、對比 20、亮部 −3、陰影 10、白色 33、鮮明度 2.5。

量測到的問題：臉頰 Y 114、皮膚 R/G 1.12（偏黃綠）、衣服 R/G 0.91（偏青）、白底段人物比背景暗很多。

最終參數：

| 參數 | 暗底組 | 白底組 |
|---|---|---|
| 色溫 / 色調 | +4 / +5 | +4 / +5 |
| 鮮明度 / 白色 / 亮部 / 對比 | 12 / 12 / −15 / 12 | 12 / 12 / −15 / 12 |
| 曝光 / 陰影 / 黑色 | 0.9 / 15 / 原值 | 1.2 / 25 / −5 |
| 創意銳利化 / Ultra Key 柔化 | 35 / 12 | 35 / 12 |

結果：臉頰 Y 從 114 升到 127（暗底）、從 111 升到 136（白底）；皮膚 R/G 1.18–1.20；衣服 R/G 1.00；無過曝。
