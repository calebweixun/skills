# 提示詞模板

實測有效的版本（見 SKILL.md 的背景說明）。`{{...}}` 是要替換的部分，
其餘文字照抄，不要自己精簡或改寫用詞——每一句都是踩過坑之後加上去的。

```
這是一份 Heptabase 匯出的白板筆記，內容用「# Note Cards」「# PDF Cards」
「# Highlights」「# Text Elements」「# Insights」「# Images」「# Videos」
「# Audios」「# Mindmaps」等固定區段列出連結。請照以下規則改寫：

1. 每一個非空區段裡的「每一個項目」都必須保留，不能省略、不能因為你
   判斷不重要就跳過——包含圖片、PDF、子筆記連結，一個都不能少。
2. 空區段（區段標題底下完全沒有項目的）整段刪除，不要保留標題。
3. 一般連結（[text](path)）改成 [[wikilink]]，wikilink 裡只放**檔名
   本身、不含任何資料夾路徑、不含副檔名**（例如原本是
   [文字](../Card%20Library/A.pdf)，要寫成 [[A]]，不是
   [[../Card Library/A.pdf]] 也不是 [[A.pdf]]）。檔名用解碼後的完整
   中文/原始檔名（不要保留 %XX 這種 URL 編碼），不要自己翻譯、簡化
   或改寫檔名。
4. 圖片連結（![text](path)）改成 ![[embed]] 格式（保留驚嘆號），
   embed 裡一樣只放檔名本身、不含資料夾路徑，但**保留副檔名**（圖片
   embed 需要副檔名才能正確顯示，例如 ![[image 33.png]]，不是
   ![[image 33]]）。
5. 最前面加上 YAML frontmatter，前後都要有 --- 分隔線：
   ---
   title: {{標題}}
   type: {{moc 或 project}}
   tags: [{{你依內容判斷的 1-3 個繁體中文標籤}}]
   source: heptabase
   ---
6. 全部項目用條列 - 列出，不用區段標題分組。
7. **整份輸出（從開頭的 --- 到最後一個項目）都要包在一個單一的
   ``` markdown 程式碼區塊裡**，不要在程式碼區塊外面加任何說明文字、
   開場白或結語。這是為了讓我能用程式精確擷取原始語法，不要省略這個
   要求。

---以下是原始內容---
{{原始檔案內容}}
---原始內容結束---
```

```
上一次輸出漏掉了以下項目，請重新輸出完整版本，一樣包在單一 ```
程式碼區塊裡，規則同上，這次不要再漏：
{{verify_migration.py 報出的缺漏清單}}
```
